Lady of the Data Lake (LDLx) Documentation

Complete operational manual for deploying the LDLx sovereign database operating system and integrating with its secure HTTPS REST API.

1. The Architectural Need It Fills

Developers and small teams frequently rely on databases, but transitioning those databases into secure, production-grade environments usually requires complex server setups, cloud hosting contracts, and intricate networking configurations.

LDLx solves this problem by functioning as a security-focused, dedicated database operating system. Instead of running a database as a background application inside a heavy general-purpose desktop or server OS, LDLx turns hardware into a streamlined, purpose-built database server.

2. Operating System Installation

LDLx can be installed onto bare-metal hardware or run as a live image using automated ISO builds.

1

Download the ISO

Visit the LDLx GitHub Releases Page and download the latest installable release asset.

2

Flash to USB

Flash the ISO image to a blank USB flash drive using Rufus, Ventoy, or dd.

3

Boot Target Hardware

Insert the USB into your target machine, boot into UEFI/BIOS settings, configure priority boot from USB, and launch the installer.

4

Kiosk Auto-Login & Execution

Upon completion and reboot, the system automatically launches into the secure LDLx environment on tty1 via systemd.

3. LDLx API Reference (`DbServerManager`)

The LDLx API exposes a secure HTTPS REST server running on port 9000 to manage local databases, rotate authentication tokens, and execute CRUD operations.

Base URL & Protocols

  • Domain / Local URL: https://lakelady.ldlx:9000 or https://<bound_ip>:9000
  • Transport: HTTPS / Secure JSON over SSL using local certificates
  • Required Headers:
    Authorization: Bearer <jwt_token>
    X-Database-Name: <database_name>
GET /health

Retrieves server status, protocol, bound IP, domain, port, target database state, available databases, and current authentication validity.

{
  "status": "UP",
  "protocol": "HTTPS",
  "server": "LDLx Unified Data Lake REST Server",
  "bound_ip": "192.168.1.50",
  "domain": "lakelady.ldlx",
  "port": 9000,
  "target_database": "core",
  "available_databases": ["core", "users", "analytics"],
  "authenticated": true
}
POST /api/auth/token

Generates a fresh cryptographic HS256 JWT token with full admin scope and invalidates all prior tokens.

{
  "status": "TOKEN_ROTATED",
  "message": "All previous tokens have been expired successfully.",
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
CRUD /api/data (GET, POST, PUT, DELETE)

Manages document records within the targeted database header context. Supports querying by field, inserting JSON payloads, updating records with automatic metadata tracking, and removing records.
